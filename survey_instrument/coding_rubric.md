# Coding Rubric — Full Version with Examples
## AI Agency in Student Learning

---

## Agency Code

### Code 1 — Passive Receipt

**Definition:** Student received output from an AI tool, search engine, or peer and submitted it with no visible engagement.

**Observable behaviours:**
- Opened ChatGPT or Google, typed question, copied answer directly without pausing
- Looked at screen briefly then wrote without re-reading
- Shared AI answer with a peer; both submitted the same text
- Submitted answer immediately after receiving AI output

**Common observer notes:**
- "Copied from phone directly"
- "Submitted AI answer unchanged"
- "Opened ChatGPT, typed question, copied answer verbatim"
- "Did not check answer, submitted immediately"

---

### Code 2 — Surface Engagement

**Definition:** Student received AI output and showed some processing before submitting, but did not actively question or verify the content.

**Observable behaviours:**
- Paused and re-read the AI output before writing
- Changed a word or two but kept the structure and meaning
- Looked uncertain, looked back at screen, then continued
- Formatted differently without engaging with meaning

**Common observer notes:**
- "Paused and reread before writing"
- "Changed a few words in AI answer before submitting"
- "Reread answer, changed subject-specific vocabulary"
- "Made minor edits to AI output"

**Key distinction from Code 3:** Did the student question the *content*, or just the *presentation*? Changing vocabulary = Code 2. Asking whether the content is correct = Code 3.

---

### Code 3 — Active Interrogation

**Definition:** Student actively questioned, verified, or substantially reworked the AI output before submitting.

**Observable behaviours:**
- Asked observer or teacher "is this right?" before writing
- Compared AI answer against textbook, notes, or second source
- Crossed out AI answer and rewrote substantially in own words
- Expressed verbal doubt ("I don't think this is right")
- Identified an error or inconsistency independently
- Used AI as starting point and substantially expanded or modified it

**Common observer notes:**
- "Asked observer if AI answer was correct before writing"
- "Compared AI answer to textbook, noted discrepancy"
- "Rewrote answer entirely in own words after reading AI output"
- "Identified error in AI output independently"

---

## Handling Difficult Cases

**AI use unclear:** Use `used_ai_or_copied = ?`. Still assign best agency code from visible behaviour. Note ambiguity.

**Student did not use AI:** Still assign agency code based on engagement with whatever resource they used. Code 1 applies to passive copying from any source.

**Non-verbal student:** Use the printed question card. Accept pointing. Note "NV" in notes column.

**Anxious or distressed student:** Skip Q2 immediately. Write "skipped" in notes. Do not push for a response.

**Contradictory response:** Trust observable behaviour over self-report for agency code. Record what was said for Q1/Q2. Note the contradiction (e.g. "claims ownership but could not explain — code 1 behaviour observed").
