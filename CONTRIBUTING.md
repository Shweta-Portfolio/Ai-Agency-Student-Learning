# Notes on Replication and Adaptation

This is a small naturalistic pilot. If you want to replicate or adapt it, here are the key decisions to be aware of.

## Adapting the observation sheet

The three-level agency code was designed to be observable without interrupting the classroom. If you have two observers, inter-rater reliability should be assessed before data collection — code the same 5–10 students independently and check for agreement before proceeding.

## Adapting the follow-up questions

Q1 and Q2 were kept deliberately simple for accessibility. In a higher-education or engineering context you could use more specific probes:
- "What would you change about this answer?"
- "Where did the key idea in this answer come from?"
- "If I removed the AI tool, could you reproduce this answer?"

## Ethics

This study was conducted as naturalistic observation within normal teaching duties and did not require formal ethics approval. Any version involving recording audio or video, students outside a teaching context, deception, or identifiable data would require full IRB/ethics committee approval before proceeding.

## Scaling up

For a version with enough statistical power to test hypotheses rather than describe patterns, approximately 150–200 students with at least two coders and a more controlled task design would be needed. This pilot was designed to demonstrate the approach and generate preliminary findings, not to support statistical inference.
